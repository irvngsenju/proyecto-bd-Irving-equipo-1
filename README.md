# Sistema de Control de Acceso - Biblioteca UTS

## Integrantes
- Irving Miranda Garcia

## Descripcion del problema
Sistema de control de acceso a la biblioteca de la
Universidad Tecnologica del Sur de Sonora (UTS).

## Tecnologias utilizadas
- SQL Server 2017
- C# Windows Forms (.NET Framework)
- Visual Studio 2022
- GitHub para control de versiones

## Modulos del sistema
- Modulo Acceso: Registro de entradas, consultas y reportes
- Modulo Prestamos: Gestion de prestamos de libros
- Modulo Computadoras: Reservacion de computadoras
